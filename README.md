# Site CCI Mayotte — administrable

Transformation du site CCI (front figé) en site administrable full-stack
pour l'examen Développeur Web et Web Mobile.

## Stack
- Front : React
- Back : Node.js / Express
- Base de données : MySQL (Sequelize) + MongoDB (historique admin)
- Sécurité : Bcrypt (mot de passe), middleware d'authentification

## Architecture
MVC (Modèle - Vue - Contrôleur)
